All required results use the default word "Robot" and pattern "circle" with a desired contact force of \(F_d = 5\) N. The bonus writes "robot" in cursive and draws the spiral, infinity and heart shapes with the robot. Everything in this report is produced by one command:

python main.py --part bonus        # bonus only (cursive word + complex shapes)

Output folders: outputs/part1 shapes · part3 impedance writing · part4 admittance writing · part5 comparison · part6 material probing · bonus. The folder names come from the given code; the README part numbers map as --part 2 impedance, 3 admittance, 4 comparison, 5 materials.

Notation

\(x\) = pen-tip position, \(x_d\) = desired position, \(\dot x\) = velocity, \(q\) = joint angles, \(\tau\) = joint torques, \(F_{meas}\) = measured contact force, \(F_d\) (or \(F_{des}\)) = desired force, \(K\) = stiffness, \(D\) or \(B\) = damping, \(m\) or \(M\) = mass, \(\Delta t = 1\) ms = simulation step. The wall/surface is modelled as in Part A: \(F_{meas} = K_e (x - x_w)\) for \(x > x_w\). Part A measures \(x\) into the wall; the code's \(z\) axis points up, so "into the surface" is \(-z\).

1Part 1: Trajectory generation (TODO 1)

Each shape is a parametric curve. A parameter \(t\) sweeps once around and gives one point per value (120 points; 360 for the spiral). The radius is \(r = \text{scale}/2 = 0.05\) m, so every shape fits in a 10 cm box.

$$\textbf{Circle:}\quad x = r\cos t,\qquad y = r\sin t,\qquad t\in[0,2\pi]$$
$$\textbf{Spiral (3 turns):}\quad \rho = \frac{r\,t}{6\pi},\qquad x=\rho\cos t,\qquad y=\rho\sin t,\qquad t\in[0,6\pi]$$
$$\textbf{Infinity (lemniscate of Gerono):}\quad x = r\sin t,\qquad y = r\sin t\cos t$$
$$\textbf{Heart:}\quad x = r\sin^3 t,\qquad y = \frac{r}{16}\big(13\cos t - 5\cos 2t - 2\cos 3t - \cos 4t\big)$$

In words: the spiral's radius grows linearly from 0 to \(r\) over three turns. The figure-eight crosses itself at the centre. The heart is the classic parametric heart, scaled by \(r/16\) so it is about 10 cm wide.

Moving the pen along a path

A whole pen-down stroke is drawn as one smooth motion, not as many stop-and-go pieces. The distance travelled along the path, \(s(t)\), follows the same minimum-jerk polynomial the given MinJerkTrajectory uses:

$$s(t) = L\,(10\tau^3 - 15\tau^4 + 6\tau^5),\qquad \tau = \frac{t}{T},\qquad T = \frac{L}{v}$$
$$\dot s(t) = \frac{L}{T}\,(30\tau^2 - 60\tau^3 + 30\tau^4)$$
$$x_d(t) = \text{path point at arc length } s(t),\qquad \dot x_d(t) = \dot s(t)\,\hat u$$

In words: \(L\) is the stroke length, \(v = 4\) cm/s is the writing speed and \(\hat u\) is the unit direction of the current path segment. The pen starts and stops at rest with no jumps in velocity or acceleration. A stroke is cut only where the path turns by more than 30° (\(\hat u_i\cdot\hat u_{i+1} < \cos 30^\circ\)), because at a real corner the pen must stop. Block letters stop at their corners; circles and cursive are drawn in one motion.

2Part 2: Cartesian impedance control (TODO 2)

Control law (same as Part A(a))

$$e_x = x_d - x,\qquad \dot e_x = \dot x_d - \dot x$$
$$F_c = \underbrace{K\,(x_d - x)}_{\text{spring}} + \underbrace{D\,(\dot x_d - \dot x)}_{\text{damper}}$$

With the robot equation of motion \(m\ddot x = F_c - F_{meas}\), the closed loop becomes a mass-spring-damper:

$$m\ddot x + D\dot x + Kx = Kx_d + D\dot x_d - F_{meas}$$

For the 7-joint arm, the Cartesian force is turned into joint torques with the Jacobian transpose. Coriolis/centrifugal and gravity terms are compensated:

$$\tau = J^T(q)\,\big[K(x_d - x) + D(\dot x_d - \dot x)\big] + C(q,\dot q)\,\dot q + g(q)$$

In words: the pen behaves as if it were held by a virtual spring \(K\) and shock absorber \(D\) attached to the target point. \(J^T\) maps the force at the pen tip to motor torques, because the power is the same in both spaces: \(F^T\dot x = F^T J\dot q = \tau^T\dot q \Rightarrow \tau = J^T F\). \(g(q)\) cancels the weight of the arm and pen, so the spring only has to do the task.

How each term is computed

  • Six dimensions. \(F_c\) has 3 forces and 3 torques; \(K\) and \(D\) are diagonal (one value per axis).
  • Orientation error. Orientations cannot be subtracted like positions, so the quaternion helper in utils.py is used: \(q_{err} = q_{cur}\otimes q_{des}^{-1}\) (sign flipped if \(w<0\)), \(e_{rot} = 2\,(x_{err}, y_{err}, z_{err}) \approx \theta\,\hat n\). The torque is \(-K_{rot}\,e_{rot} - D_{rot}\,\omega\).
  • Damping from a damping ratio. The same \(\zeta\) relation as Part A(d), with the arm's effective mass \(m = 2\) kg (0.05 kg·m² for rotation): $$D = 2\,\zeta\,\sqrt{K\,m}\qquad\Longleftrightarrow\qquad \zeta = \frac{D}{2\sqrt{K m}}$$
  • \(C(q,\dot q)\dot q\) and \(g(q)\) come from PyBullet inverse dynamics: \(g(q) = \mathrm{ID}(q, 0, 0)\) plus the tool weight \(J^T[0,0,m_{tool}g]\) (given gravity_compensation), and \(C(q,\dot q)\dot q = \mathrm{ID}(q,\dot q,0) - \mathrm{ID}(q,0,0)\).
  • Damping the velocity error \((\dot x_d - \dot x)\), as in the notes, matters. Damping plain \(\dot x\) would resist the writing motion itself: with \(D \approx 100\) N·s/m at up to 7.5 cm/s, the pen would trail the path by up to \(D\dot x/K \approx 1\) cm.

Getting 5 N with impedance control (TODO 2, continued)

At rest (\(\ddot x = \dot x = 0\)) the closed-loop equation reduces to \(F_{meas} = K(x_d - x)\). So the target is placed \(F_d/K_z\) below the surface. A slow integral of the force error adds the rest:

$$z_d = z_{touch} - \frac{F_d + F_I}{K_z},\qquad F_I = K_I\int (F_d - F_{meas})\,dt,\qquad K_z = 150\ \text{N/m},\ K_I = 5\ \text{s}^{-1}$$

In words: \(z_{touch}\) is the height where the pen just touches. A 150 N/m spring placed 3.3 cm below the surface pushes with 5 N. But the surface is not perfectly rigid: the pen sinks in a little, and the force becomes \(F = F_d\,K_c/(K_z + K_c) \approx 4.2\) N, where \(K_c \approx 750\) N/m is the measured contact stiffness. The integral term pushes the target slightly deeper until the average force is exactly 5 N. It only integrates while the pen is touching, so it cannot "wind up" in the air. Without it, the RMSE is 0.88 N instead of 0.53 N.

3Part 3: Admittance control (TODO 3)

Control law (same as Part A(a))

$$M_v\,\ddot x_c + B_v\,\dot x_c = F_{des} - F_{meas},\qquad M_v = 1.5\ \text{kg},\ B_v = 60\ \text{N}\cdot\text{s/m}$$

The commanded position \(x_c\) is then tracked by a stiff inner position loop (the impedance controller with the given 600 N/m gains and \(\dot x_d = 0\) along \(z\)):

$$\tau = J^T\big[k_p(x_c - x) - k_d\,\dot x\big] + g(q)$$

In words: the robot imagines a small mass \(M_v\) on a damper \(B_v\) that is pushed by the force error. Too much force pushes this imaginary mass away from the surface; too little lets it sink. A stiff position controller then follows it.

Discrete update every \(\Delta t = 1\) ms (explicit Euler)

$$\ddot x_c = \frac{F_{meas} - F_{des} - B_v\,\dot x_c}{M_v},\qquad \dot x_c \leftarrow \dot x_c + \ddot x_c\,\Delta t,\qquad x_c \leftarrow x_c + \dot x_c\,\Delta t$$
$$z_d = z_{touch} - 15\ \text{mm} + x_c,\qquad |\dot x_c| \le 0.08\ \text{m/s},\quad |x_c| \le 0.03\ \text{m}$$

In words: acceleration → velocity → position, one small step at a time (both values are clipped by the given limits). The sign is \(F_{meas} - F_{des}\) here only because the code's \(x_c\) points up, away from the surface (Part A's \(x_c\) points into the wall). It is the same law. At rest \(\ddot x_c = \dot x_c = 0\), so \(F_{meas} = F_{des}\) exactly. This is the DC gain \(G(0) = 1\) derived in Part A(c), independent of the stiffness.

Connection to Part A(c)–(e)

With the inner loop stiff, the force loop is the Part A transfer function:

$$\frac{F_{meas}(s)}{F_{des}(s)} = \frac{K_e}{M_v s^2 + B_v s + K_e},\qquad \omega_n = \sqrt{\frac{K_e}{M_v}},\qquad \zeta = \frac{B_v}{2\sqrt{M_v K_e}}$$

In the simulation, the "environment" seen by the outer loop is the inner-loop spring \(k_p = 600\) N/m in series with the pen–table contact (\(K_c \approx 750\) N/m). The measured value is \(K_e \approx 336\) N/m (from \(600\cdot750/1350 \approx 333\)). So:

$$\omega_n = \sqrt{336/1.5} \approx 15\ \text{rad/s},\qquad \zeta = \frac{60}{2\sqrt{1.5\cdot 336}} \approx 1.34$$
$$B_{v,crit} = 2\sqrt{M_v K_e} = 2\sqrt{1.5\cdot 336} \approx 45\ \text{N}\cdot\text{s/m}$$

The given \(B_v = 60\) is exactly the Part A(d) rule for an unknown environment, using the stiffest environment possible here. That is a rigid wall, for which the series stiffness can never exceed \(k_p = 600\) N/m:

$$B_v \ge 2\sqrt{M_v\,K_{e,max}} = 2\sqrt{1.5\cdot 600} = 60\ \text{N}\cdot\text{s/m}$$

Why the last row fails (Part A(e)): the commanded acceleration \(\ddot x_c = (F_{des} - F_{meas} - B_v\dot x_c)/M_v\) gets very large when \(M_v\) is small. In discrete time, the velocity update multiplies \(\dot x_c\) by \(1 - B_v\Delta t/M_v\) every step, which is stable only if

$$\Big|1 - \frac{B_v\,\Delta t}{M_v}\Big| < 1 \quad\Longleftrightarrow\quad M_v > \frac{B_v\,\Delta t}{2} = 0.03\ \text{kg}$$

With \(M_v = 0.015\) kg the factor is \(-3\), so \(\dot x_c\) flips sign and grows every step. It slams between the ±0.08 m/s clip and the force loop never settles. This is the sampling/delay limit described in the notes (\(M_v > K_eT^2/7.5\) for the simplified delay model). In this simulation the 1 ms integration step is the first limit reached. On a real robot, the inner position loop's finite bandwidth and sensor delays make \(T\) much larger. Combined with a stiff environment (\(\Delta F_{meas} = K_e\,\Delta x\)), this is why admittance control struggles on hard surfaces.

4Part 4: Performance metrics and comparison (TODO 4)

$$\text{RMSE} = \sqrt{\frac{1}{N}\sum_{i=1}^{N}\big(F_{meas,i} - F_{d,i}\big)^2}\qquad\text{over all samples with } F_{d,i} > 0$$
$$\text{Smoothness} = \frac{1}{N}\sum_{i=1}^{N}\big\lVert \dddot x_i \big\rVert^2,\qquad \dot x = \frac{\Delta x}{\Delta t},\ \ \ddot x = \frac{\Delta \dot x}{\Delta t},\ \ \dddot x = \frac{\Delta \ddot x}{\Delta t}\ \ \text{(central differences)}$$

In words: RMSE squares each force error, averages them and takes the square root. The result is one number in newtons for "how far from 5 N, on average". Squaring makes big errors (impact spikes) count much more than small ones. \(F_d > 0\) only while the pen is writing; it becomes 5 N at the moment of first contact (see Section 7). Jerk is the rate of change of acceleration, so a smaller mean squared jerk means a smoother motion (unit m²/s⁶).

Discussion

Geometry. Both controllers write a clear "Robot" and a round circle with ≈2 mm mean error. The largest error (6.5 mm) is the small tick at the start of the circle. The pen-up jump from the "t" to the circle is 11.5 cm in 0.5 s, and the arm's inertia (no \(M(q)\) feed-forward in the control law) leaves the pen a few millimetres behind when it lands.

Impedance. The soft 150 N/m normal spring makes landings gentle (peak 6.5 N), and the integral term brings the mean force to 4.90 N. Its remaining error is spread along the strokes: dips and bumps where a stroke starts, stops or turns a corner. The arm's acceleration in the plane couples into the soft \(z\) axis.

Admittance. Once the pen has settled, admittance is the better force regulator (0.28 N vs 0.40 N). The virtual mass keeps moving until the force error is exactly zero, so it has no steady-state error. Its weak point is the landing: each stroke starts with a 15 mm step command through the stiff 600 N/m inner loop, which gives force spikes of up to 7.9 N before the outer loop reacts. 77 % of its squared error comes from the first 0.5 s after landings. With only two landings in cursive writing (Section 6), its RMSE drops to 0.40 N.

Smoothness. The stiff inner loop of admittance passes contact transients straight into the motion, so its mean squared jerk is about 3.5× higher. Triple differentiation of 1 kHz data amplifies small vibrations, so this metric mainly reflects the landings.

5Part 5: Haptic material identification (TODO 5–6)

The probe presses \(d_{cmd} = 10\) mm past the point of first contact with the given 600 N/m impedance gains, and records the force \(F_i\) against the depth \(d_i\). The stiffness is the slope of the best straight line through the origin, \(F = K d\):

$$E(K) = \sum_i (F_i - K d_i)^2,\qquad \frac{dE}{dK} = -2\sum_i d_i\,(F_i - K d_i) = 0\quad\Longrightarrow\quad \hat K = \frac{\sum_i d_i F_i}{\sum_i d_i^2}$$
$$\text{class} = \begin{cases}\text{soft} & \hat K < 250\ \text{N/m}\\ \text{medium} & 250 \le \hat K < 350\ \text{N/m}\\ \text{hard} & \hat K \ge 350\ \text{N/m}\end{cases}$$

In words: press, record force against depth, and pick the slope that makes the squared distance of all points to the line as small as possible. The thresholds are MATERIAL_CLASS_THRESHOLDS from utils.py. As in the given code, \(d_i\) is the commanded depth.

The series-compliance effect

The robot is not rigid: it is a 600 N/m virtual spring \(K_r\) pressing on a pad of stiffness \(K_e\). Two springs in series carry the same force:

$$F = K_r\,(d_{cmd} - d_{act}) = K_e\,d_{act}\quad\Longrightarrow\quad d_{act} = \frac{K_r}{K_r + K_e}\,d_{cmd}$$
$$\Longrightarrow\quad F = \underbrace{\frac{K_r K_e}{K_r + K_e}}_{\hat K}\,d_{cmd}$$
$$\frac{1}{\hat K} = \frac{1}{K_r} + \frac{1}{K_e},\qquad \hat K < K_r = 600\ \text{N/m always},\qquad K_e = \frac{K_r\,\hat K}{K_r - \hat K}\ \ \text{(inverse)}$$

Observations. All three pads are classified correctly. \(F/(d_{cmd}-d_{act}) = 600\) N/m for every pad, which confirms the series model exactly. Putting the measured pad stiffness into \(K_rK_e/(K_r+K_e)\) reproduces \(\hat K\) to within 2 %.

Consequence. \(\hat K\) can never exceed \(K_r = 600\) N/m, and it flattens out as the pad gets harder. A 13× spread in the pad parameter (300 → 4000) becomes only a 2.1× spread in \(\hat K\) (179 → 385). This is why the class thresholds (250, 350 N/m) are far below the nominal pad values, and why a pad harder than C would be almost impossible to tell apart from it. For hard materials, the robot's own softness dominates the measurement. (The actual-depth values 250/665/1088 N/m are lower than the PyBullet parameters because its soft-contact model, with the tool's own contact stiffness and damping, is not an ideal spring. The ordering is preserved.)

Remedies. Fit against the actual penetration from forward kinematics (gives 250 / 665 / 1088 N/m), invert the series formula \(K_e = K_r\hat K/(K_r - \hat K)\) (gives 256 / 659 / 1076 N/m), or probe with a much stiffer controller. The short spike at first contact in Figure 5 is the impact; a slower approach would reduce it.

6Bonus: cursive writing and complex shapes

Cursive "robot"

Each lowercase letter is a handful of control points in a unit box (baseline 0, small letters up to 0.5, tall letters up to 1). Each letter begins where the previous one ended, so the whole word is one chain of points. A Catmull–Rom spline draws a smooth curve that passes exactly through every point:

$$p(t) = \tfrac12\Big[\,2p_1 + (p_2 - p_0)\,t + (2p_0 - 5p_1 + 4p_2 - p_3)\,t^2$$
$$\qquad\qquad + \,(3p_1 - p_0 - 3p_2 + p_3)\,t^3\Big],\qquad t\in[0,1]$$

In words: between every pair of points \(p_1 \to p_2\), the curve uses the neighbours \(p_0\) and \(p_3\) to set its direction, so the joins have no kinks. The end points are repeated so the curve reaches them; 12 samples are taken per segment. The pen never lifts inside the word. The cross of the "t" is added afterwards as a short separate stroke, as in real handwriting. Only the letters r, o, b and t are defined (enough for "robot"); other letters raise a clear error. The path is then drawn with the same minimum-jerk path timing (Section 1) and the same controllers.

Live dashboard

With --live, a matplotlib window (plt.ion(), Tk backend) opens next to the simulation. In writing mode it shows the desired vs actual path (pen-down only) and the desired vs measured force over time. In probing mode it shows the loading curve (force vs commanded depth) and, at the end, the fitted line \(F = \hat K d\). It redraws at most 20 times per second so the 1 kHz simulation is not slowed down. When it closes, the last frame is saved as *_dashboard.png. On a machine without a display, it falls back to drawing off-screen and still saves the file.
